## Cinema-project-TA-23A
Clone repository:
```bash
git clone https://github.com/Tallinna-Polutehnikum/TA23A-A7-projekt.git
```
Change directory either to server or client:
```bash
cd client
```
```bash
cd server
```
Install required node modules:
```bash
npm i
```
Run localhost server:
```bash
npm run dev
```
